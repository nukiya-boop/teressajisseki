# 介護実績管理（テレッサ自動入力）

ケアマネ・事業所の書類（PDF）を取り込むと、訪問ごとの **サービス実施記録** を自動で作るウェブアプリです。

- サービス提供票・利用票から、訪問介護の予定（日付・時間・サービス）を読み取る
- 訪問介護計画書から、訪問枠ごとの具体的な援助内容を読み取り、**レ点欄を自動入力**
- アセスメントシートの ☑ から介護度・認知症自立度・歩行器使用を読み取り、**記録コメントを介護度・認知症に合わせて自動作成**
  （例：「訪問時、居間でテレビを見て過ごされていた」「おむつ交換時、腰を上げる協力動作があった」「作話がみられたが否定せず傾聴した」）。
  時間帯（朝・昼・夜）、季節、アセスメントの ADL（洗身・更衣・服薬など）に合わせて文を選び、同じ訪問では同じ文になります
- シフト・実績（CSV）があれば突き合わせ、予定・シフト・実績が揃った訪問に「テレッサ（○）」をつける
- ヘルパーの在籍期間を貼り付けると、担当者が決まっていない訪問に **ヘルパーを自動で振り分け**
  （在籍期間内の人だけ、同じ時間に2か所へ行かない・移動時間をあける・1日の上限時間を超えない。
  同じ訪問枠には同じ人が続けて入りやすく、担当時間が偏らないようにする。
  入らない訪問は担当の入れ替えを試す。開始は予定より遅らせない。ちょうど続く訪問は前の訪問の終了を1分早める
  （時間区分が変わる場合は早めない）。前倒しは設定した分まで（初期値は前倒しなし））
- 紙の「サービス実施記録」と同じ様式で A4 に 2件ずつ印刷、CSV 出力

サーバー不要で、ブラウザだけで動きます（データはブラウザ内の IndexedDB に保存）。PDF・ZIP の読み取りには
cdnjs から pdf.js・JSZip を読み込むため、インターネット接続が必要です。

## 使い方

1. `index.html` をブラウザで開く（または `npm start` → http://localhost:8080）
2. ① に利用者の書類フォルダの ZIP、または PDF をまとめてドロップ
3. 対象月を選ぶと、その月の訪問ごとにレ点・コメントが入った記録が並ぶ
4. ② で訪問枠ごとのレ点の根拠（どの計画書の何番か）を確認、必要なら「編集」
5. ③ の行をクリックすると、その日の記録だけを直せる。内容を確認したら「記録内容を確認した」
6. 「サービス実施記録を印刷」または「CSV出力」

自動で作るコメントは下書きです。実際の様子と違う内容は必ず直してから記録として使ってください。

### 読み取る書類

| 書類 | 読み取る内容 |
|---|---|
| サービス提供票・利用票 | 年月、利用者名、被保険者番号、要介護度、訪問介護の予定日・時間・サービス |
| 訪問介護計画書 | 作成日ごとの版、訪問枠（時間帯・曜日・サービス区分）、サービスの具体的内容 → レ点 |
| アセスメントシート | ☑ の付いた要介護度・認知症自立度（Ⅱa 以上で認知症の記録文）・歩行器 |
| ケアプラン第2表 | 訪問介護の行のサービス内容と頻度（訪問介護計画書がないときに使用） |

レ点は **ケアプラン優先** で決めます。

1. 訪問枠の手動設定があればそれを使う
2. ケアプラン第2表（その日に有効な版）の援助内容と頻度を当てる。週2回の入浴のように訪問回数より少ないものは、
   訪問介護計画書で曜日が決まっていればその曜日、なければ訪問曜日から均等に選んだ曜日だけにつける
3. 訪問介護計画書（その日に有効な版で、種別・曜日・時刻が合う枠）の内容で補う

同じ月にサービス利用票と提供票があれば、利用票の予定を使います。
事前チェック（顔色・発汗・体温等）と退室確認（火元・電気・水道・戸締り）は毎回つけます。
ケアプラン第1表の要介護状態区分は丸囲みが文字に残らないため読みません。スキャン画像の PDF は文字が取れないので読めません。

### CSV で取り込む場合

`samples/` に見本の CSV があります。Shift_JIS（Excel 保存）の CSV も読めます。

## 取り込み形式（1行目は見出し）

| 種類 | 列 |
|---|---|
| ケアプラン | 利用者ID, 利用者名, 曜日（例: `月水金`）, 開始, 終了, サービス内容, サービスコード |
| シフト | 日付, 担当者, 開始, 終了 |
| 実績 | 日付, 利用者ID, 開始, 終了, サービス内容, 担当者 |

ケアプラン・シフトは反映のたびに置き換え、実績は追記されます。

## テレッサの判定ルール（`js/logic.js`）

| 状態 | 条件 |
|---|---|
| テレッサ ○ | 予定あり・実績あり・担当者のシフト内・予定との時間差が許容誤差以内 |
| 時間差あり | 開始または終了が予定から許容誤差（既定10分）を超えてずれている |
| シフト外 | 実績の担当者がその時間にシフトに入っていない |
| 未実績 | 予定はあるが実績がまだない |
| 計画外 | ケアプランにない実績 |
