# 介護実績管理（テレッサ自動付与）

ケアプラン・シフト・実績を取り込むと月間の実績表に反映され、
**予定・シフト・実績の3つが揃った訪問に自動で「テレッサ（○）」がつく** ウェブアプリです。
サーバー不要で、ブラウザだけで動きます（データはブラウザ内に保存）。

## 使い方

1. `index.html` をブラウザで開く（または `npm start` → http://localhost:8080）
2. 対象月を選ぶ
3. ① ケアプラン ② シフト ③ 実績 に CSV をドロップ、または Excel から表を貼り付けて「反映」
4. 実績表が自動作成され、条件を満たす行にテレッサがつく
5. 「未実績を予定どおり確定」で、シフトから担当者が決まる予定を一括で実績化
6. 「CSV出力」「印刷」で書き出し

`samples/` に見本の CSV があります。Shift_JIS（Excel 保存）の CSV も読めます。

## 取り込み形式（1行目は見出し）

| 種類 | 列 |
|---|---|
| ケアプラン | 利用者ID, 利用者名, 曜日（例: `月水金`）, 開始, 終了, サービス内容, サービスコード |
| シフト | 日付, 担当者, 開始, 終了 |
| 実績 | 日付, 利用者ID, 開始, 終了, サービス内容, 担当者 |

ケアプラン・シフトは反映のたびに置き換え、実績は追記されます。

## 判定ルール（`js/logic.js`）

| 状態 | 条件 |
|---|---|
| テレッサ ○ | 予定あり・実績あり・担当者のシフト内・予定との時間差が許容誤差以内 |
| 時間差あり | 開始または終了が予定から許容誤差（既定10分）を超えてずれている |
| シフト外 | 実績の担当者がその時間にシフトに入っていない |
| 未実績 | 予定はあるが実績がまだない |
| 計画外 | ケアプランにない実績 |
