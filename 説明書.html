実績管理アプリ 説明書

サービス実施記録・出勤簿・勤務体制一覧表を、毎月かんたんに出すためのアプリです。

1. アプリを開く

  1. もらった 実績管理アプリ_v○.zip を右クリック →「すべて展開」
  2. できた jisseki-app フォルダの中の index.html をダブルクリック（Chrome か Edge で開きます）
  3. 初めて使うパソコンでは、データを読み込む を押して、もらった 実績管理データ_○○.json を選ぶ →「置き換えますか」で OK
一度読み込めば、ブラウザを閉じてもデータは残ります。次からは index.html を開くだけです。
PDF の書類を取り込むときは、インターネットにつながっている必要があります。

2. 毎月の書類を出す

  1. 画面いちばん上の「毎月の書類」で、◀ 前の月 次の月 ▶ を押して月を選ぶ
  2. 出したい書類のボタンを押す
  3. 印刷画面が開くので、そのまま印刷するか、プリンターを「PDFに保存」にして保存
ボタン出るもの
サービス実施記録（全員）その月の全員分（利用者順・日付順、A4に2件ずつ）
出勤簿ヘルパー1人1ページ。左の選択欄で「すべて」か1人を選ぶ
勤務体制一覧表A4横。日ごとのサービス提供時間
勤務体制一覧表（CSV） 実績（CSV）Excel で開けるファイルを保存

新しい月の書類を取り込むとき

  1. 「① 書類を取り込む」に、提供票・実績の PDF（ZIP のままでも可）をドロップ
  2. 「③ ヘルパー」に新しく入った人がいれば、1行で書いて 反映
    例：山田太郎 2026年11月1日〜現在 常勤（辞めた人は「〜11月30日」のように終わりの日を書く）
    後ろに「管理者」「サ責」「常勤」「非常勤」「兼務」と書くと、勤務体制一覧表に入ります。
  3. 「④ 実績・サービス実施記録」で内容を確認し、違うところは行をクリックして直す
記録のコメントは書類から作った文です。実際の様子と違うところは、必ず直してから使ってください。

3. ほかの人と共有する

A. 書類だけ渡す（いちばん簡単）

「毎月の書類」で「PDFに保存」したファイルを、社内の共有フォルダなどで渡します。相手はアプリがなくても見られます。

守ってほしいこと
  • データを直す人は1人に決める。データはそれぞれのパソコンの中に保存され、自動ではそろいません。2人が別々に直すと、どちらかの変更が消えます。
  • 直したら、その人が データを保存（ファイル） で新しい json を作って配り直す。ファイル名に日付が入るので、いちばん新しい日付のものを使う。
  • json を読み込むと、そのパソコンのデータは置き換わります（前の内容は消えます）。
個人情報の注意
  • json ファイルと書類の PDF には、利用者の名前・被保険者番号、ヘルパーの名前が入っています。
  • メールに添付するときはパスワードを付け、共有は社内の共有フォルダなど、決まった人だけが開ける場所でしてください。
  • だれでも開けるリンクや、公開のホームページには置かないでください。
